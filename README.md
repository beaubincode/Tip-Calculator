# 💰 Tip Calculator

A clean and intuitive web application designed to help users quickly calculate tip amounts and split bills evenly among multiple people. 

## 🚀 Live Demo

[View Live Project](https://beaubincode.github.io/your-repo-name/)

---

## ✨ Features

- **Custom Tip Percentages:** Choose from preset percentages (e.g., 5%, 10%, 15%, 20%) or enter a custom percentage.
- **Bill Splitting:** Instantly split the total bill evenly across any number of people.
- **Real-Time Calculation:** Updates tip per person and total bill per person dynamically as inputs change.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
- **Input Validation:** Prevents negative numbers and zero-person calculations with user-friendly error prompts.

---

## 🛠️ Built With

- **HTML5** – Structure and semantic markup
- **CSS3 / Flexbox / Grid** – Custom styling and responsive layout
- **JavaScript (ES6+)** – Dynamic calculation logic and DOM manipulation
